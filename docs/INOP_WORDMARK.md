# Original INOP lettering

Only four letters; no standalone symbol or monogram. Original SVG paths, no font/stock artwork dependency. Three distinct letterings were actually rendered in Chromium on navy, sidebar, mobile and small-wordmark contexts:
A: rounded continuous monoline (selected); B: solid cut typography; C: angular technical lettering with I terminals and octagonal O.
A is restrained, legible and optically balanced in small navigation placements. It takes inspiration from continuous technology lettering without copying NASA's official letters or graphic. The selected four paths are shared by login, sidebar, mobile topbar and drawer. Light/dark/auto colors remain available.
A horizontal four-letter favicon at 16px would reduce glyph height to about 3px. The favicon therefore uses the same four paths in two rows (IN/OP) only in the browser tab; this is a technical abbreviation of placement, not a new application symbol. All app surfaces keep the horizontal INOP wordmark.
Actual preview: `/workspace/work/critical-login/wordmark-concepts.png`. Favicon reuses the selected paths and the regression checks this equality. No gradients, icon-only component or separate brand emblem remains in the application.
