# Package 6: constrained branding

The supplied reference is used only for the four-letter silhouette. The original logo palette, login background, architecture asset, lighting, CSS, layout, form handlers and responsive rules are unchanged. No image of a login screen is used. No platform subtitle or decorative symbol is added.

One reusable INOPLogo uses wordmarkPaths for login/sidebar/mobile/drawer. The favicon uses the same paths in a compact IN/OP layout: a horizontal four-letter wordmark is not legible in a 16px tab. It still contains only the four letters, no separate symbol. SVG is vector-only and adapts to light/dark browser chrome. Font/reference metallic shading is deliberately not copied because the existing color tone must remain unchanged.

AZ headline is exactly “Bütün əməliyyatlar üçün vahid platforma.” EN/RU convey the same meaning. The second brand explanation is removed from the component and locale data. No auth/JWT or reset-password behavior changes.
