# Private source-command / ingestion foundation

Internal default-disabled preparation, not a public intake API or live storage claim. `createIntake` requires trusted server storage/scanner dependencies. Test transports are explicitly `evidenceMode=test`; clients cannot choose mode, keys, ownership, grants, scan verdict or parser result. No runtime env flag, router, automatic DDL/worker or Candidate/Application creation is enabled by this increment.

The new `HrCvIntake` model records a server-owned immutable original reference, exact bytes/hash/MIME/name, server actor/assignment/department snapshot and hash of actor + UUID command. Reusing a command with changed bytes/type/mode/version is 409. Original reference is reserved in Mongo before immutable object PUT; uncertain write/DB acknowledgement resumes that same row/key and exact readback. No original/source/record is deleted. No TTL/legacy backfill; retention and deletion policy remain separate approvals.

Preparation DDL: `hr_intake_command_unique` commandKey unique; `hr_intake_queue_slot` queueSlot unique partial number (64 slots); `hr_intake_actor_slot` createdBy+actorSlot unique partial number (4 slots per actor); `hr_intake_claim` state/nextAttemptAt/leaseUntil/createdAt. Schema autoCreate/autoIndex=false; worker checks exact unique/partial indexes before use. Production preparation needs explicit backup/DDL approval; no production commands are run. Idempotent named index creation must be reconciled with actual hosted metadata before activation.

Upload and worker enforce fresh independent Candidate.read/create with existing JWT revocation/current DB role and server scope fields. Read/original only require fresh Candidate.read scope; foreign ids, missing grants/department and changed context fail closed. Input bytes and metadata are copied before awaits; scanner/provider cannot mutate the parser's owned snapshot. Only clean exact-hash scan unlocks bounded real rules-2 parsing or original download. Infected/unknown scan and changed bytes are quarantine/blocked states, never a fake empty result. Source facts have pending HR review, truthful heuristic confidence/version; 0 is retained and unknown contact/facts are not manufactured. Raw text/key/lease/command are omitted from DTOs. No automatic decision/person/application write occurs.

Persisted queued/running/retry/ready/blocked/quarantined/failed/cancelled states use exact intake-rules-1 profile, 60s lease, three attempts, bounded retry/backoff and stale-token CAS. Expired exhausted lease releases capacity while retaining source/object. Old task facts are withheld/not claimed, but verified old original can remain readable. Two shared process IO slots stay occupied until ignored-cancellation work actually settles; 15s outer deadline does not create unbounded detached operations. Abandoned reserved uploads remain tracked/private and need approved reconciliation, not blind deletion.

Actual owned-loopback Mongo/JWT/rules parser + synthetic private storage/scanner tests cover five scopes, default-off/DDL, immutable replay/readback/lost DB/PUT acknowledgements, quotas, transient outage, obsolete/expired/raced leases, byte/metadata mutation, scan/role revocation, private originals and malformed/oversized/type/traversal input. Synthetic clean scanner is NOT malware certification; local storage is NOT real durability/recovery.
