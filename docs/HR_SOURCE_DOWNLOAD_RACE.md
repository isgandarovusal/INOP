# Source-document download race investigation

AUD-090 retained the original concurrent test timeout rather than treating a serial pass as a fix. Investigation found that the editor's private preview context includes the Source read status. Focus revalidation changes ready → loading and correctly disposes/revokes the preview URL. A native PDF download used that same URL; when focus occurs between click propagation and the anchor's native action, the original bytes are no longer accessible.

A purpose-built Chromium test forces that actual focus/refetch boundary, records create/revoke/click/focus events, and verifies downloaded bytes. Before patch, the ordinary download passes but the focus case returns `canceled`; the old download also bypasses a fresh server refusal by reusing cached preview bytes. Evidence: `/workspace/inop-hr13h-race-baseline-valid.log`1pass/3fail. The earlier all-zero run used an incorrect visibility wait for an intentionally empty ready-state marker and is not product evidence.

The preview still closes/revokes immediately on focus, route or permission changes. An explicit download now requests the same authorized `/file` API anew using Bearer and its own abortable current-context action; it uses a separate short-lived Blob URL, revoked in the next event turn after native dispatch. 401/403/404 also clears the cached preview. Other preview consumers retain their existing callback-free behavior. StrictMode, backend scopes and API contracts remain unchanged.

Passing evidence: initial four-suite concurrent61/61; final tightened Source/race concurrent28/28 includes actual exact file bytes, fresh403 with no new private URL, late file200 after permission loss with no download, primary data retained on auxiliary error, focus revocation and URL cleanup. Cleanup asserts every created URL is revoked once as a multiset: independent download URLs are legitimately revoked before the earlier preview URL, so creation order is not a lifecycle invariant.

The original historical timeout lacks event traces, so its exact trigger cannot be retroactively proven. This closes the now reproducible and regression-tested focus/revocation failure, rather than claiming every browser/resource timeout has the same cause. Complete current frontend regression remains a separate release gate. No backend/production/provider/storage/secret/deployment change.
