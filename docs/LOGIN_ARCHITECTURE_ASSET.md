The fictional corporate architecture visualization was generated specifically for INOP with the session image-generation tool on 2026-10-14. No stock photograph, landmark, third-party reference image or screenshot was copied. It is an AI-generated illustration used under the tool/service usage terms; no exclusive copyright claim is made.

Original retained outside Git: `/workspace/generated_images/exec-79af6f52-88cb-46dc-aa2b-8e65f931df10.png` (1536×1024). Shipped asset: `Frontend/src/assets/brand/login-architecture.webp`, 1200×800, quality 76, approximately 50 KB. ImageMagick was used only for requested resizing/format compression. The scene contains no interface, text, logo, people or real user data.

The picture's desktop source uses a min-width 681px media condition. Mobile receives only a transparent inline SVG fallback; CSS hides decoration. Explicit intrinsic dimensions, async decoding and a bounded, absolutely positioned picture prevent layout shifts. The image is decorative with empty alt, not a whole-page screenshot background. A top fade protects live HTML text contrast. Login validation/auth handlers and HR styles remain unchanged.

Actual login screenshots at 1440, 768 and 390 were reviewed after replacement of the former dark geometry. The page uses a light composition and a separate white card. The former IO mark is replaced in the following wordmark package.
