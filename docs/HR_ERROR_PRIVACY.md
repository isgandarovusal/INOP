# 10A — error privacy boundary

The actual unauthenticated malformed-JSON endpoint logs the body-parser Error, including raw request body/parse excerpts. HR CRUD/pipeline/export catch blocks likewise serialize raw errors, which may include Mongoose document values, contact fields, file content/paths, credentials and nested causes. The isolated negative tests use only a synthetic marker, capturing logs in memory; marker/credential values are never printed. An injected database failure tests the actual Candidate HTTP catch boundary without writing any record; it is fault injection, not a claim of a naturally occurring DB outage.

`safeErrorLog.service` emits only fixed category and validated HTTP status; no error object/name/message/code, stack, body, cause, request, headers, document, file or provider payload is serialized. Global error handling and Candidate/Job/Application/pipeline/export catch blocks use it. Existing structured validation, ID, duplicate and Multer responses preserve status/code/field contracts. Unknown global error messages/details are generic in development as well as production, so JSON parse excerpts do not leak into responses. Existing controllers' explicit translated business responses are unchanged.

This increment covers those named boundaries, not a claim that every other application's logging, reverse proxy, external AI provider, SMTP transport or hosting retention policy has been audited. `notFoundHandler`'s existing path response is unchanged; do not place credentials/CV content in URLs. Safe aggregate counters are not candidate event history; existing authorized HR activity/history persists separately.

`Backend/tests/hrErrorPrivacy.test.cjs` covers actual malformed JSON, injected Candidate DB failure, validation/cast/duplicate/unknown errors, Multer size/type status contracts and JSON-size error privacy. Existing private upload, mixed resource scope and complete regression suites preserve legal flows. No environment/secret/storage/provider configuration, production data or migration changes.
